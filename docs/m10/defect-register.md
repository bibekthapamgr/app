# M10 — Defect register

**Milestone:** M10 · Every defect M10's testing, its reviews and its CI runs found, with its severity, where it was found, what was done and the evidence. Severity: **critical** (a leak around the proxy, a credential exposed, or the app unusable), **high** (a release-blocking failure of a core function, or a security weakness), **medium** (a function that works but misleads or fails in a common case; a test or a CI check that fails without a defect in the app, which blocks releases all the same), **low** (cosmetic, rare, or affects a configuration V1 doesn't ship). A release candidate has none open above low.
